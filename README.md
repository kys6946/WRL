# NRL — Node Rendering Library(yes the project name changed after the repo creation bruh)

> ⚠️ **Work in Progress**

NRL (Node Rendering Library) is a C++ rendering library currently in its early stages of development.

The project is **far from finished**, and the API, architecture, and project structure are expected to change as development progresses. Breaking changes are therefore to be expected.

## Current state

For now, NRL is very limited. The main functionality currently implemented is:

* SDL3 initialization
* Window creation
* Basic window management
* Basic `Node` / `Window` structure

Rendering features are still under development.

## Requirements

* C++20 compiler
* CMake 3.20+
* SDL3
* Git

## Building

Clone the repository and enter the project directory:

```bash
git clone https://github.com/kys6946/WRL.git
cd WRL
```

Configure the project with CMake:

```bash
cmake -S . -B build
```

Build the project:

```bash
cmake --build build
```

The example executable will be generated in:

```text
build/nrl_example
```

You can run it with:

```bash
./build/nrl_example
```

## Testing / Experimenting

If you want to quickly test something while developing NRL, you can modify the example `main.cpp`.

The example is located in:

```text
examples/main.cpp
```

You can use this file to experiment with the current NRL API and test new functionality.

For example, the current API can be used to create a window:

```cpp
Transform transform;

transform.scale.x = 600;
transform.scale.y = 400;

Window window("NRL Test", transform);
```

## Example limitation

The example setup is currently very basic.

At the moment, **only one `.cpp` file should be placed inside the `examples` directory**.

Having multiple `.cpp` files there will result in a CMake error, multiple test file compilation is not currently handled by the CMake configuration.

This will be improved later so that multiple examples can be built as separate executables.

For now, use:

```text
examples/
└── main.cpp
```

rather than:

```text
examples/
├── main.cpp
├── test.cpp
└── another_test.cpp
```

## Project structure

The current structure is approximately:

```text
WRL/
├── CMakeLists.txt
├── include/
│   ├── node.hpp
│   ├── window.hpp
│   └── type.h
├── src/
│   └── window.cpp
├── examples/
│   └── main.cpp
└── build/
```

The `build/` directory is generated by CMake and should not be committed to the repository.

## Roadmap

The project is still in its early development, so the roadmap is subject to change.

Possible future work includes:

* Rendering primitives
* Text rendering
* Texture/image rendering
* More Node types
* Better transformation handling
* Input/event handling
* Multiple example executables
* Improved cross-platform support
* Cleaner rendering and window abstractions

More features will be added as the architecture develops.

## Status

**Early development — expect changes.**

NRL is currently more of an experimental project and a foundation for future development than a complete rendering library.
